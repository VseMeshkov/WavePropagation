# Лабораторная работа №1: Восстановление скорости волны в 3D волновом уравнении

Восстановление неизвестного параметра `c` (скорости распространения волны) в 3D волновом уравнении по наблюдениям поля смещения `u(x, y, z, t)`.

## Уравнение

$$\frac{\partial^2 u}{\partial t^2} = c^2 \nabla^2 u + f(x, y, z, t)$$

## Задача

Дано:
- Наблюдения поля `u(x, y, z, t)` в 3D-домене
- Гипотеза о структуре уравнения (волновое уравнение)
- Два источника данных: однородная и неоднородная среда

Найти:
- Скалярный параметр `c` (скорость волны)

## Метод

| Компонент | Решение |
|-----------|---------|
| Представление уравнения | DAG через `networkx` (3 типа узлов: наблюдаемые, параметры, латентные) |
| Численный солвер | Явная схема «крест» (FD, 7-точечный лапласиан) |
| Устойчивость | Условие Куранта + фиксированные суб-шаги (`n_substeps=4`) |
| Инициализация | Формула Тейлора (нулевая начальная скорость) |
| Функция потерь | MSE по 5 равномерно распределённым кадрам времени |
| Оптимизация | Multi-start: грубая сетка + L-BFGS-B из топ-3 точек |


## Данные

**Источник 1 — Однородная среда**  
Аналитическое решение: `u = sin(πx)·sin(πy)·sin(πz)·cos(ωt)`, где `ω = π√3·c`.  
Истинное значение: `c = 1.0`.

**Источник 2 — Неоднородная среда**  
Численное решение с полем скоростей `c(x,y,z) = c₀·(1 + 0.5·exp(-r²/0.1))`.  
Диапазон: `c ∈ [1.0, 1.5]`, среднее `⟨c⟩ ≈ 1.20`.

Параметры сетки: `40×40×40`, `N_t = 300`, `T = 2.0`.

## Результаты

| Метрика | Значение |
|---------|----------|
| Истинное `c` (однородная) | `1.0` |
| Найденное `c` (однородная) | `1.0003` |
| Относительная ошибка | `0.03%` |
| Улучшение vs `c = 0.5` | `2×10⁷` раз |
| Найденное `c` (неоднородная) | `1.2017 ≈ ⟨c_field⟩` |
